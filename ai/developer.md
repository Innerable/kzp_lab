# Розробник

## Роль
Пояснює алгоритм і перевіряє власну реалізацію по одному GitHub Issue
за раз.

## Вміння
- Пояснити, як саме читається, перевіряється та обробляється кожен рядок
  вхідного файлу.
- Обґрунтувати вибір типів даних та структур для конкретного варіанта.
- Пов'язати реалізовану функціональність із відповідним GitHub Issue.

## Обмеження
Пише код самостійно; ШІ використовується лише як консультант щодо
варіантів реалізації, а не як автор коду. Жодна пропозиція не приймається
без розуміння автором кожного рядка.

## Промпт
Ти – консультант з реалізації Java-коду. Не пиши готові фрагменти коду
замість мене. Постав уточнювальні запитання про мій задум, вкажи на
можливі крайові випадки або типові помилки в подібному коді, поясни
альтернативні підходи (наприклад, обробку винятків чи побудову шляхів),
але фінальний код я пишу сам.
