# Реєстр студентів — консольний звіт

## Призначення

Програма читає записи реєстру студентів з `data/input.csv`, перевіряє їх
коректність, обчислює показники успішності та формує звіт у консоль і файл
`out/report.txt`.

Варіант завдання: **№ 6 — Реєстр студентів**
(курс «Кросплатформні засоби програмування», лабораторна робота № 1).

## Формат вхідних даних

Файл `data/input.csv` кодовано в UTF-8. Один запис — один рядок, поля
розділено крапкою з комою `;`. Десяткові числа записують із крапкою.

Формат запису:

```
name:String; group:String; course:int; average:double; scholarship:boolean
```

Приклад:

```
Петренко Іван;КІ-101;2;4.5;true
Коваленко Марія;КІ-102;3;4.8;true
Іванов Олег;КІ-101;1;3.9;false
```

Рядок вважається хибним і пропускається (з повідомленням про причину), якщо:
- він порожній;
- кількість полів не дорівнює 5;
- ім'я або назва групи порожні;
- поле `course` або `average` не є числом;
- `course` або `average` від'ємні.

## Показники звіту

1. Кількість коректних записів
2. Середній бал (`average`)
3. Найбільший бал (`average`)
4. Кількість стипендіатів (`scholarship == true`)

## Вимоги до середовища

- Java 21 (JDK)
- Maven Wrapper додано в репозиторій — окрема установка Maven не потрібна

Перевірка версії Java:

```bash
java -version
```

## Збірка та запуск

Усі команди виконуються з кореня репозиторію.

### Компіляція

```bash
./mvnw compile
```

### Запуск тестів

```bash
./mvnw test
```

### Повна перевірка (тести + статичний аналіз)

```bash
./mvnw verify
```

### Створення виконуваного JAR

```bash
./mvnw package
```

JAR з'явиться у `target/lab01-1.0.0.jar`.

### Запуск програми

Зі стандартними шляхами (`data/input.csv` → `out/report.txt`):

```bash
java -jar target/lab01-1.0.0.jar
```

З власними шляхами до вхідного та вихідного файлів:

```bash
java -jar target/lab01-1.0.0.jar --input data/input.csv --output out/report.txt
```

Довідка про параметри запуску:

```bash
java -jar target/lab01-1.0.0.jar --help
```
Довідка про версію лабораторної:

```bash
java -jar target/lab01-1.0.0.jar --version
```
### Повна перезбірка з нуля

```bash
./mvnw clean verify
```
